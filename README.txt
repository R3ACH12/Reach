REACH, a Jason Production
=========================

This folder is the standalone version of REACH. It runs in any modern
browser (Chrome, Edge or Firefox) with an internet connection.
It is graphics-heavy: on a slower computer it lowers its own resolution
to keep running smoothly. Headphones make it much scarier.

PLAY SOLO
  Double-click index.html.

PLAY CO-OP WITH VOICE CHAT (2 to 4 players)
  Co-op and voice need the game to be online, so put it on a website:

  Option A: itch.io
    1. Make a free account at itch.io and click "Upload new project".
    2. Set "Kind of project" to HTML.
    3. Upload REACH-standalone.zip and tick "This file will be played in the browser".
    4. Set the viewport to 1280 x 720 and turn on the fullscreen button.
    5. Save. You can make it free, pay-what-you-want, or paid.

  Option B: GitHub Pages
    1. Make a public repository and upload index.html.
    2. Settings > Pages > Deploy from branch > main > Save.
    3. Your game is live at https://YOUR-NAME.github.io/REPOSITORY-NAME/

IN THE GAME
  One player presses "Host co-op" and sends the 5-letter room code (or the
  invite link) to friends, who press "Join". Everyone who wants voice chat
  turns it on in Settings. Teammates hear you when you are near them,
  and so does the creature.

CONTROLS
  WASD move, Shift run, C crouch, F flashlight, E use (hold for some
  things), M mute your mic, Esc pause.
